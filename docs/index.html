科學實證數據

天然礦物質鹼性還原水 (ARW) 的實驗數據顯示令人驚異的健康功效

🛡️

抗癌效果

減慢擴散速度

實驗顯示飲用ARW的白鼠癌細胞擴散及生長速度明顯減慢，癌轉移數量由 350 降至 147。

數據來源：韓國高麗院研究數據
📊

糖尿病改善

血糖值顯著下降

以OLETF老鼠為對象進行10周試驗，飲用ARW一組的血糖值與對照組相比出現顯著下降，由 203 降至 131 mg/dl。

數據來源：OLETF大鼠實驗
📉

膽固醇改善

LDL↓ HDL↑

膽固醇總濃度不但降低，壞膽固醇(LDL)減少，而好膽固醇(HDL)反而增加。三酸甘油脂由 285 降至 120 mg/dl。

數據來源：臨床實驗數據
🧪

抗氧化及免疫

自由基顯著減少

飲用ARW後肝臟、肺、腎臟等處的活性氧數量顯著減少，脾臟的活性氧數量強而多，證明ARW不僅具有抗氧化作用，更能提高免疫功能。

數據來源：DAFH-DA檢測實驗

六角水美肌秘密

✓ 六角水優勢

  • • 六角水分子結構與人體肌膚水分子相近，容易被肌膚吸收
  • • 水分和養分迅速注入肌膚，令細胞營潤飽滿
  • • 有效活化細胞能量傳遞，加速新陳代謝及肌膚更生

✗ 一般水分子

  • • 水分子結構不穩定，不容易被吸收
  • • 水分和養分未能完全注入肌膚細胞
  • • 細胞脆弱，更生功能下降

使用方法

簡單四步，即可享用健康六角水

1

倒入食水

將自來水或過濾水倒入 WaveQ 水壺中，容量最多2公升

2

按下按鈕

只需按下「Q」按鈕，機器自動開始運作

3

等待7分鐘

通過磁場渦旋運動和遠紅外線處理，自動生成六角水

4

享用健康水

天然礦物質鹼性還原水即刻完成，可直接飲用
